# 首位角色三维结构草模 v01

日期：2026-11-03。状态：可打开、可旋转的静态三维初稿，**不是已精确还原三视图的成品角色，也不能直接作为已绑定桌宠使用**。

## 文件

- `character-v01.blend`：Blender 4.2 源工程，按功能集合分组，可编辑独立网格与材质。
- `character-v01.glb`：独立三维网格与材质，约2.3MB；无需图片投影即可从任意方向查看。
- `viewer.html`：内嵌GLB的离线WebGL2查看器。浏览器打开即可拖动旋转、滚轮缩放，含正/侧/背及隐藏头发按钮，无网络/CDN依赖。
- `preview-sheet.png`：实际模型四视角渲染拼图。不是图像生成工具制作的三维效果图。
- `preview-*.png`：透明背景单角度渲染。
- `model-report.json`、`file-validation.json`、`reimport-validation.json`、`viewer-validation.json`：实际结构及检查记录。

用户指定白色提亮版12暂定为最终三视图，作为当前三维设计基线，原图不修改。

参考文件：`../../concepts/turnaround-v02-accessories-v12.png`。

本机未找到已安装Blender或已连接的图片转三维工具；插件查询连接失败。为完成真实模型初稿，在项目忽略的tmp目录准备独立Python3.11与官方PyPI bpy4.2轮包，使用参考规格驱动的程序化建模。**这不是AI多视图重建，也不是对图片像素的精确三维恢复。**

已有结构：躯干与四肢、五指/足部、异瞳、精灵耳、独立猫耳发饰、头部花饰与蝴蝶结、绿宝石项链、上衣与七分裙、真实空隙与花形线圈组成的裙边、腰后尾饰及双层脚环。猫尾蝴蝶结有实际厚度，侧面自然呈窄视角。底层身体、头发、头饰、脸部、胸饰、上衣、下装、尾饰、脚部集合分开。

## 已知差距：不能当成已验收美术资产

- 面部相似度不足：脸型、眼部贴合、发际线和刘海仍明显区别于版12。
- 卷发用规则截面的独立发束近似，仍显重复；背部覆盖手臂的关系、蓬松轮廓未完全匹配。
- 袖子、露肩裁切、领口与裙边细节只做结构近似，不能宣称和参考一致。
- 腕部/手指、脚部为独立几何拼接，后续需连续拓扑与蒙皮；没有完成变形测试。
- 无生产用UV贴图图集、表情形变、骨骼、动作、头发/裙摆物理；分件模型不等于可直接换装。
- GLB包含316个网格节点、约108872三角形，需要后续合批、减面和性能优化。
- 渲染使用真实灯光，不会完全等同插画手绘光影；预览页用简化光照，颜色也可能略不同。

因此本次交付用途是检查三维体积、部件结构与导入链路；下一步应先精修头脸、头发、服装轮廓，对照正侧背逐项验收，再拓扑/UV/绑定，不宜直接批量做舞蹈。

## 复现

1. 用已有Python运行 `scripts/setup-modeling-runtime.py`，仅在项目tmp下载依赖；轮包按PyPI公布SHA256校验，不全局安装。
2. `./tmp/modeling-runtime/python311/python.exe scripts/build-character-model.py`
3. 使用带Pillow的Python运行 `scripts/package-model-preview.py`。
4. `./tmp/modeling-runtime/python311/python.exe scripts/verify-character-model.py`
5. 查看器验证：`node scripts/verify-model-viewer.cjs <playwright模块路径>`，脚本默认使用本机Chrome。

Blender导出API依据：[Blender官方glTF导出接口](https://docs.blender.org/api/4.2/bpy.ops.export_scene.html)。这不代表官方对本模型质量进行了认证。
