# 两天原型、七天公开测试版 · 实施与验收计划

日期：2026-11-07 · 状态：应用计划待执行；已做历史三维试修，二维样机尚未验收
需求基线：[PRD](./PRD.md) · 技术基线：[接口契约](./architecture-contracts.md)

## 1. 时间与前提

2026-11-07 已确认转二维，先完成 [二维样机 G0–G5](character-2d-pipeline.md#5-验证样机与通过条件待执行)：A 类外观/素体看图确认→分层日常动作→点击及站坐过渡→场景和桌面→可编辑/换装→性能与可复现。B 类参考尚待提供。具体软件和 MCP 兼容性先验证，不把历史 GLB 或示例模型通过当作本角色二维通过。以下 D1–D7 是应用冲刺目标，需在二维素材管线和服务依赖满足后重新估算。

D1–D7 是开工后的连续项目日，不对应已承诺的日历发布日期。此前讨论的七天为冲刺目标，不包含商店审核或证书签发时间。所有工期为估算，未做代码/依赖运行验证。

两天原型允许占位素材和开发配置，但必须标明；七天公开版必须使用有授权的正式素材、真实模型配置和实际通过的核心用例。公开版包含 PRD 的全部 P0，语音不属于首版。若无法满足必须延期或经需求变更调整公开范围，不以演示代替验收。

本轮增补：MVP 需完成本地大模型端口与配置预留，Ollama 完整连接为后续核心迭代，不挤入七天功能承诺。每次完成文档、代码或素材更新均按 [GitHub 协作与同步](./version-control.md) 提交并推送；远端未配置或推送失败必须明确记录“未同步”。

资源假设：单平台；一位开发执行者；用户及时提供参考图、模型访问方式、目标测试机及发布决策。当前仅文档，无已实现功能。后续若使用并行协作，另依用户授权与实际环境安排，本计划不假设已有团队。

## 3. 可裁减与不可静默裁减

可裁减：动画精细度、待机变体、背景装饰、可选音效、模型供应商数量、安装方式从安装器改为解压运行（需更新发布说明与数据清除指引）。

不可静默裁减：固定场景/角色、双类基础互动、文字多轮、可控持久记忆、基础电脑操作、权限与停止、本地资料和国际化接口、桌面可正常使用。真正壁纸降成普通窗口属于产品范围变更，不属于已达标。

若 D2 未贯通记忆与工具主流程：先取消装饰优化，更新剩余估算；D5 仍有数据丢失/越权/桌面无法正常使用问题，暂停公开发布。七天是目标，不得通过“忽略缺陷”达成。

## 5. 发布质量闸门

阻断缺陷：启动/退出不可用、桌面图标无法正常操作、数据丢失、凭证泄露、越权或重复副作用、必需 P0 缺失、素材授权不明、安装包无法在声明支持环境运行。发布前必须修复或明确改变支持范围并更新文档。

可带已知问题：不影响核心任务的轻微动画跳变、装饰细节、不支持的 Windows 版本/多屏环境（需明确排除）；每项需记录影响、规避和后续计划。

发布资料：

- [ ] 带版本的安装/解压包、文件摘要、GitHub 已推送提交标识及发布标签。
- [ ] 真实演示、安装/使用/退出/数据清除说明。
- [ ] 角色/场景许可、第三方 notices、模型连接和费用说明。
- [ ] 支持矩阵、性能基线、验收报告、未解决问题。
- [ ] 无密钥与私人测试数据；默认关闭权限/统计/自启。
- [ ] 正式反馈入口、中文隐私说明和 AI 能力边界。
- [ ] 产品负责人对具体候选包的发布审阅。本文不执行发布。

## 7. 本轮新增验收

MVP 契约验收：ModelConnection 区分协议/部署位置；testConnection/listModels/inspectModel/generate/cancel 端口明确；用假本地适配器验证可替换而不修改角色、记忆和任务模块。此项不能标为真实 Ollama 接入通过。

后续 Ollama 实现时必须执行：服务未启动、模型列表为空、模型不存在、正常流式聊天、冷启动等待、取消与迟到响应、切换模型、无工具能力降级、有工具能力仍需权限、无云凭证可聊天、断开外网后真正本地模型工作、内存/GPU 资源竞争。模型版本和硬件配置记录在测试报告；本地运行不承诺所有机器同样速度。

GitHub 同步验收：检查忽略规则、git diff --check、确认待提交文件无密钥/个人数据→提交→推送→记录 commit/branch/remote。推送失败保留本地提交并报告，不强推、不伪造远端已更新。每个完成的更新批次至少一次成功推送；不要求每次编辑器保存产生提交。
