## A 类 v10 的头身与腿长

参照战法、魔道、小魔女、缔造的 v01 全身设计。战法的长裙遮住腿部关节，主要用于判断头的相对大小。魔道、小魔女和缔造的短裙版本提供更多可见腿段，估核时计入姿势、透视与鞋底的影响。

正面底稿以头顶至下巴为一头高，头顶至足底约为 6.6 个头高，胯下至足底约占全身的 54%。此前 v09 分别约为 5.0 个头高和 49%。这些数值来自两张站立底稿的像素地标，供同尺度核对。使用 v10 检查大腿和小腿的长度分配，以及膝踝位置。历史对照图为 [A 类 v09](base-a-mage-v09.png)。

## A 与 B 的身高差

用相同缩放倍率摆放两张正面底稿，将赤足足底对齐在同一地面线上。从头顶量至足底，排除发量、头饰和鞋跟。半个头按 A v10 的头顶到下巴计算。弓箭手可略高于魔法师，身高差上限为半个 A 类头高。当前 B v07 与 A v10 接近齐高，正面图的头顶估量相差约 1 像素。

派生弓箭手角色时，将 B v07 的站立身高与头身关系一同带入设计。在单人构图中用人物本身的头身关系和腿段长度核对比例。需要判断 A/B 身高差时，提供同尺度并排的站立参考。

## 优先保持体型外形与身材比例

开始设计前查看对应类型的当前 PNG，并将该图作为生成或编辑的体型、头身关系、腿长和肤色参考输入。

默认保持所选底稿的：

- 头部相对全身的大小、头身关系、颈肩关系和身体整体高度比例。
- 躯干与腿长的关系，上臂/前臂、大腿/小腿的相对长度和围度。
- 肩宽、腰线、胯部宽度与身体外轮廓；不混用 A 的头部比例和 B 的身体。
- 腿部轴线及自然轮廓、手掌/脚掌大小、手指脚趾的纤细和圆润程度。“圆润末端”不等于把四肢或手脚增粗。
- 对应底稿的皮肤底色与柔和连续明暗；头部、手臂、手足和腿部要属于同一肤色体系。

换发型、衣服或饰品时，在身体基准上增加设计。服装的厚度、裙摆和袖型可形成自己的外轮廓，人物的肩、腰、胯与四肢继续依据底稿。用户明确要求修订默认体型或比例时，按新的设计方向制作并更新当前参考，保存版本记录及此前确认的图稿。

## 参考输入与检查方法

每张输入图写明作用：

```text
体型/比例/肤色主参考：所选类型的当前底稿 PNG（A v10 或 B v07）。
同尺度站立身高：B 比 A 至多高半个 A 类头高，以赤足足底和头顶对照。
服饰/发型/饰品参考：用户本次提供的图片，仅提取指定特征。
本轮新增：用户指定的外观设计。
保持：底稿的体型外形、头身关系、躯干与四肢比例、手足大小和肤色。
```

产出后先把身体地标与底稿对齐，再检查外观设计。只作整体等比缩放；头顶（排除发量/发饰）、下巴、肩、肘、腕、胯、膝、踝和足底的相对关系应能对上。不能单独拉长腿、缩小头或拉宽身躯后声称“比例一致”。衣物遮住的身体按基准保留，不把遮挡当成自动更换体型的理由。两张底稿在相似画布高度展示不代表其真实厘米身高相同；没有已测定的真实身高或固定头身数值，不杜撰还原度百分比。

颜色以实际底稿同材质、相似受光区域为主，色名仅辅助沟通：整体为低饱和浅粉象牙白，局部受光常接近 `#FEF0ED`–`#FEF2EF`，阴影同色系连续变化，腮红只作轻微局部效果。具体取样见清单，不能用单一色值覆盖整张脸或把肤色改成冷灰、橘红。修色或去噪时保护五官、手足和轮廓；若要求其他区域严格不变，采用已授权的局部方法并验证选区外像素，避免整图生成引入色差块或重影。

## 版本边界

旧设计稿、旧三视图和中间候选保留作历史/局部特征参考，不替代上述已确认身体底稿。A/B 的眼色记录分开，不能把魔法师红蓝异瞳套给弓箭手；后续用户明确的五官定制仍按本轮变更执行。

底稿是单张正面合成 PNG，作为当前二维分层与绑定前的外观依据；确认它不等于已获得侧/背面隐藏结构、分层 PSD、Cubism 工程、绑定或动画。三维制作也不能由底稿是否相似来代替实际网格/绑定验证。
