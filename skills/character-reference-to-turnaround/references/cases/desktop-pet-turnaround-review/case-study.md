# DesktopPet 三视图修订案例

这些对照聚焦方向、遮挡、部件数量和腿型。生成新角色时，以本轮认可的角色设计、比例底稿与[三视图流程](../../workflow.md#三视图)为准。

## A 类小魔女的菊花与背发

[问题稿 v01](little-witch-01-turnaround-v01.png) · [修订对照 v03](little-witch-01-turnaround-v03.png)

- **菊花换侧**。正面画面左边的唯一白菊花固定在角色右鬓、鹿耳饰前方。v01 中栏标着 RIGHT PROFILE，鼻尖实际朝左，却把右鬓菊花画在近侧。v03 的鼻尖、前胸和鞋尖朝画面右侧，右鬓菊花位于近侧。背视只在画面右上方露出少量花瓣。
- **后发叠压错误**。v01 后视的部分长发绕在袖口和裙片两侧，与正、侧视确定的身后落向对不上。v03 的主发束从后颈连贯垂到膝附近，在观察者一侧覆盖后披肩、腰带和上部裙片的重叠处。核对时从发根沿发束看到发梢，检查穿过手臂、衣片或从身前绕出的断层。

## A 类魔道的兔饰缺件

[问题稿 v01](witch-scholar-01-turnaround-v01.png) · [修订对照 v02](witch-scholar-01-turnaround-v02.png)

- 单个兔饰固定在角色右侧头发上，由兔脸和两只兔耳组成。v01 正面能看见两耳，背面画面右上方只剩一耳。v02 在同一挂点补齐背视的第二只耳朵，两只耳尖从发顶露出，兔脸由头发遮挡。
- 核对挂点与组成数量，再按各视图的真实遮挡检查可见部分。此例的两只耳朵都应露出。右视中鼻尖朝右，近侧兔饰只显示兔脸的侧面。

## B 类旅人的腿粗与 O 形腿

[问题稿 v01](traveler-01-turnaround-v01.png) · [修订对照 v02](traveler-01-turnaround-v02.png)

- v01 的大腿及小腿轮廓较宽，膝下腿肚外凸使正背视呈现用户指出的 O 形观感。v02 收细大腿和膝下至袜口的轮廓，正背视的膝、踝走向更顺，右视的腿肚后缘以浅弧过渡。
- 对照 B 类底稿检查每侧大腿根、膝、踝的位置，再看大腿和小腿在相同相对高度上的宽度。核对三栏的腿长、站距与足底线，并检查袜口和鞋型是否随原服饰设计保留。用原比例比较腿段形状，避免把这组图的像素宽度当作其他角色的固定数值。

以上图例为 DesktopPet 中 `little-witch-01`、`witch-scholar-01` 与 `traveler-01` 的 `concepts` 目录下的同名原尺寸存档。
