## 1. 原素材如何转成设定

16张小尺寸角色图片提供身份、原身体比例、服饰与动作线索。最初设计生成实际使用角色1、5、8、10，其他素材仍保留用于对照。模糊像素不能证明裙边、手指或隐藏背部的精确结构；用用户明确文字补充，并将推定与确认分开。

本角色确认项：

| 项目 | 本案例要求 |
|---|---|
| 风格比例 | 娇小可爱，保留参考比例与纤细四肢；圆润仅指末端减小尖角，不增加肢体围度 |
| 异瞳 | 角色自身左红右蓝；正面观者左蓝右红，不通过镜像改变身份 |
| 头发 | 纯白、蓬松微卷；发长后来以正面自然最低发束接近手腕为准，三方向一致 |
| 耳部 | 精灵耳是耳部结构；顶部猫耳为单独佩戴装饰，猫耳背后小花不属于精灵耳后部 |
| 服装 | 白色不透明露肩上衣与七分长裙，露脚踝、脚环与光脚；保持娇小比例 |
| 颈饰 | 绿宝石项链；侧面应显示其实际侧向投影 |
| 尾饰 | 佩戴式，挂点后调到臀部上缘近骶骨的背中线；侧面蝴蝶结应收窄，不贴正面蝴蝶结 |
| 手足 | 末端圆钝、手指不尖、足部小而薄；不以延长脚尖代替整体脚长调整 |
| 毛发遮挡 | 长发主体在背后，背视图应覆盖手臂，仅露手腕/手掌；调整位置不改变颜色和蓬松 |
| 分件 | hair、headwear、face、chest_accessory、upper、lower、waist、feet；是制作分类，不代表二维图已分网格 |

用户提出过脚踝衔接角约100°–105°、双层脚环且花仅朝前、微笑保留小嘴宽度等局部目标；相关多项合改分支曾被否定并回退v02，不能把每项历史要求自动叠加到最新图。继续修改时按用户当前目标和明确底图处理。

## 4. 配色、降噪及可复现证据

颜色不是仅靠“冷白皮”色名决定。用户指定参考部位后，以其受光区域取样，并区分底色、阴影、腮红和边缘抗锯齿。

| 处理 | 实际方法与局限 |
|---|---|
| 背景归一 | 从边界连通近白区域识别背景并转纯白，避免把白发白裙一并刷白 |
| 保边降噪 | 两轮保边平滑并保护明显边缘；允许细微纹理被平滑，不保证所有材质无损 |
| 肤色 | 参考侧面小腿 ROI x=732,y=840,w=7,h=36；沟通色名“低饱和浅粉象牙白／带极淡粉调的瓷白”，中间色约#FEEEEA；非通用标准色名 |
| 版11配色 | 使用材质/位置选区调整色度，保留明暗；因此未自动解决白发白裙原有灰影 |
| 版12提亮 | 白色选区用连续曲线 `c'=c+(255-c)*0.32*weight`，平滑选择权重，保护暗线和饰物；不是从参考图自动拟合的色阶匹配 |

已记录的局部代理：平坦背景 ROI 的RGB标准差约0.533→0；小腿高频残差约0.281→0.101。版12选区外像素、alpha与原纯白像素变化为0，上部白材质及裙布的亮度代理上升。它们是指定选区的统计，不证明全图无噪声、三维光照正确或显示器校准。

具体细节读版10、11、12的 `.md` 和 `-qa.json`；正式掩模为 [配色选区](processing/color-match-final-mask.png) 与 [白色选区](processing/white-final-mask.png)。不采用历史硬阈值造成碎斑的失败预览。

[processing](processing/) 中的4个脚本是当时实际使用的源代码快照，依赖 Windows / PowerShell 7 / System.Drawing，区域与阈值针对1536×1024的本角色布局。它们不是任意角色通用降噪器。安装到新位置后，脚本默认路径不再适用；如需复现，应明确传入本包实际输入路径、参考路径、独立可写的新输出路径和掩模路径，先读参数，不直接执行旧命令。不要覆盖案例原件，也不在本次整理中重跑生成/后处理。

## 6. 可复用做法与适用边界

- 唯一底图、指定特征参考、修改区域与保持项必须分开记录；“参考v03尾巴”不是允许恢复v03全部设计。
- 整图生成连续漂移时回退认可版，缩小区域，使用适当掩模/合成或授权的确定性处理；提示词“其他不变”不是像素保证。
- 手势、脚长、脚踝过渡、末端圆润、发长、发质、色彩应作为独立变量处理。
- 图像候选、用户认可、暂定最终、失败输出和未保存尝试分别标注；最新文件名不等于最新认可基线。
- 本案例没有把三视图自动变成生产级三维角色。已交付程序化草模后来被用户否定，用户后续试用Tripo及Meshy；工具和授权调研属于另一个阶段，不将其变成这个二维skill的固定供应商依赖。

需要执行通用流程时返回 [workflow.md](../../workflow.md)；需要新角色记录模板时使用 [工作簿](../../../assets/character-workbook.md)。本案例保留原材料供追溯，新任务按用户要求选择相关部分，而不是重放所有历史步骤。
