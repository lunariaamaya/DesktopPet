# 程序化修复：背景、保边降噪与新肤色

日期：2026-11-02。方式：用户明确允许的程序化图像后处理（C# / System.Drawing / PowerShell），**未使用生成式新图作为交付底图**。

## 输入与输出

- 原版：turnaround-v02-accessories-v08.png，保留不修改。
- 仅降噪：turnaround-v02-accessories-v09.png。
- 降噪＋用户本轮指定肤色：turnaround-v02-accessories-v10.png，当前候选。
- 脚本：scripts/denoise-character.ps1 与 denoise-character.cs。
- 实测区域数据：turnaround-v02-accessories-v10-qa.json。

之前尝试图像生成式修复时，背景亮度标准差由0.532858变为0.532728，几乎未改善，因此该生成结果没有作为项目交付资产。

## 实际处理

1. 从边界四连通寻找近白背景（RGB最低通道≥250、通道差≤2），仅该掩模归一为纯白。共932,122像素，不将所有白色衣裙整体填白。
2. 两遍RGB双边滤波，半径3/5、空间sigma1.5/2.5、颜色sigma7/10。邻接通道差>28的强边缘保留原始值，保护线稿；不移动像素、不生成轮廓、无缩放。
3. 皮肤在本图布局限定区域内结合软色彩掩模微调，排除眼睛/宝石/裙边等非皮肤区域。以新参考图指定小腿区域均值为目标，RGB偏移约(+0.2024,+3.2778,+3.8730)，共影响67,229个皮肤候选像素；保留原有明暗差。
4. 输出无损PNG，仍为1536×1024。脚本拒绝覆盖已存在文件。皮肤区域坐标只适用于当前1536×1024布局，不是通用人物分割器。

## 新参考色与描述

用户「三视图.png」指定侧视小腿、脚环上方区域。单点：(735,830) #FEEDE9，(735,850) #FEEEEA，(735,870) #FEEFEB，(732,860) #FEEEE9。参考均值使用 x732–738、y840–875 的7×36区域。

描述名：**低饱和浅粉象牙白**，也可说「带极淡粉调的瓷白肤色」。这是沟通用描述，不是唯一标准色名；近似受光基准 #FEEEEA（RGB254,238,234）。比纯白多一点淡粉血色，不是灰蓝冷白，也不是鲜桃红/橙色。

推荐下次描述：「肤色用低饱和浅粉象牙白，受光面参考 #FEEEEA；白底带极淡粉调，不泛红、不偏橙、不发灰蓝，阴影柔和连续。」这些像素来自带光照的插画，不等于三维材质的物理反照率。

## 验证与限制

同一区域，原版→新版：

| 区域 | 指标 | 原版08 | 新版10 |
|---|---|---|---|
| 背景 x10–59/y500–599 | 平均RGB | 254.1606/254.0620/254.1584 | 255/255/255 |
| 背景 | 亮度标准差 | 0.532858 | 0 |
| 小腿 x732–738/y840–875 | 平均RGB | 254.0119/234.8889/229.7976 | 253.9921/237.7659/233.7460 |
| 小腿 | 水平高频残差均值 | 0.281085 | 0.100529（约下降64%） |

高频残差=通道像素与左右邻点均值之差的绝对值均值，只是局部噪声代理指标，不证明全图所有斑块已消失。保边滤波也会平滑细微绘画纹理，强边缘附近和大尺度原有阴影不全部重绘；深度/光照没有三维验证。

重复执行输出PNG的SHA256一致：164B70073D685F95EDA74B6B03C927093B415749B8D1DA7B3444137436F32EEF。复跑副本保存在忽略的tmp目录，没有作为正式资产重复发布。当前结果已目视检查，待用户复核低对比度显示下的观感。

运行示例（Windows PowerShell 7/.NET当前运行时，参考图需用户本地持有）：

```powershell
./scripts/denoise-character.ps1 -OutputPath './tmp/new-output.png' -SkinReferencePath '<参考三视图的绝对路径>'
```

省略 SkinReferencePath 仅降噪。脚本不是调用模型的提示词，不含密钥，无需联网。
