# 白色材质提亮版12

日期：2026-11-02。程序化后处理；输入版11，输出 turnaround-v02-accessories-v12.png。用户要求头发和裙子比版11更白，接近参考三视图观感，不改变造型。

## 暗沉原因与修复

版11是指定配饰色度匹配，刻意保留了版10的明暗，头发主体与白裙没有整体提亮。因此版10中偏深的灰影也沿用下来；其平均色虽然偏白，但密集卷发和衣褶灰影会使整体观感发灰。此轮不将其误归因为新背景噪声。

本轮在白色材质区域使用连续向白色靠拢的曲线：channel'=channel+(255-channel)×0.32×weight。暗线与高饱和配饰通过软选区保护；颜色选择场作局部平滑，图像本身不模糊。纯白不变，灰色阴影提亮但不填平。未重新生成、移动、缩放或改变头发/衣服轮廓。

参考图用于视觉确定白色目标与布局校验；本模式的亮度曲线是经预览选定的固定参数，不是从参考图自动拟合或逐像素复制，也不声称精确色阶匹配。肤色和已匹配饰物不作为本轮提亮目标，边缘抗锯齿或近白像素可能纳入软选区。

## 验证

详细指标见 turnaround-v02-accessories-v12-qa.json。

- 尺寸1536×1024，alpha及原纯白像素未变。
- 白色选区外像素变化为0；没有空间重采样。
- 本轮变更像素中的头发/上部白色区域平均亮度代理225.72→233.49，裙布区域237.81→242.89（0–255）。上部区域也包括与头发重叠的白色袖口等，不将其标为严格语义分割统计。
- 单独预览与正式运行输出SHA256应相同，已复跑核对；正式输出另存，版11保留。
- 预览时排除了一次会在阈值边缘产生碎斑的方案，正式版只使用经过选区平滑后的曲线，临时失败预览不入库。

这不是三维材质、物理灯光或显示器校准；用户仍需按实际显示条件确认白度。过度提亮会损失层次，因此没有将全部阴影变成纯白。

## 复现

```powershell
./scripts/match-character-colors.ps1 -BrightenWhites -InputPath './assets/characters/first-character/concepts/turnaround-v02-accessories-v11.png' -ReferencePath './assets/characters/first-character/concepts/turnaround-v02.png' -OutputPath './tmp/white-output.png' -MaskPath './tmp/white-mask.png'
```

脚本保留原先材质匹配模式，只有指定 -BrightenWhites 才进入白色提亮模式。拒绝覆盖已有输出，无需联网。
