# 制作流程

按当前任务读取相应部分。完整制作先读“素材”“设计”“三视图”，局部修改可直接从“修订与回退”开始。模板位于 `../assets/character-workbook.md`。

## 素材与设定

保留原图和视频，不覆盖、不将游戏 UI 当角色设计。建立文件索引：文件名、尺寸/时长、可见方向、能证明的细节、遮挡与可信度。素材较多时先做联系表，再查看原尺寸局部；放大仅辅助观察，不代表增加原始细节。

视频先读分辨率、帧率、时长；全段稀疏抽样定位动作，再针对关键时段检查连续原始帧。记录实际检查范围。重复帧、光效和低清手指不能支持精确动作复刻；单镜头视频也不能补足隐藏结构和三维深度。

将用户文字与图像分开记录。文字明确但图片模糊时，采用文字；存在明确冲突且会改变身份或造型时再确认。记录素材权利来源或用户声明，不把声明写成已完成权属鉴定。

需要锁定的信息：

| 项目 | 必须说明的歧义 |
|---|---|
| 身份与风格 | 原比例、头身比、纤细程度；不默认萌系就要大头或胖四肢 |
| 左右 | 以角色自身为准，另注明观者方向；不对非对称角色随意镜像 |
| 头发 | 底色、长度参照点、卷束/蓬松、前后位置；渐变是否允许 |
| 附属物 | 生理结构还是佩戴配饰，挂点、固定方式、是否独立摆动 |
| 服装 | 层数、裙长、对称性、露出范围、背面推定和材质 |
| 手足 | 姿态、掌心方向、厚薄和末端形状；角度要求应注明两条测量轴 |
| 分件 | 外观分类、可替换项、可动项；不意味着现在已存在可拆网格 |

对隐藏部位只做必要推定，并注明。若头发遮住后背，主三视图可保留自然遮挡，另作结构补充小图；不要未经要求移开发型来露出所有部件。

## 设计候选

输入图分别标记为身份/比例参考、服装参考、颜色参考、动作参考，不把所有图当作同等底图。设计稿优先解决身份、轮廓、服饰、材质，而非复杂舞台或戏剧性光照。通常正面全身配必要局部即可；背面和侧面结构留待三视图阶段统一。

提示词骨架：

```text
任务：依据身份与比例参考生成角色设计候选。
输入角色：A=主体外观；B=服装细节；C=指定配色（如有）。
必须保留：已确认的比例、发型、非对称标记、服饰与装饰归属。
本轮设计：仅列当前允许补全的项目；不确定项单独说明。
画面：完整人物、清楚轮廓、适合后续多视图解释的柔和中性光。
禁止漂移：列本角色真正存在的高风险项，不堆无关负面词。
```

检查头身比例、四肢围度、裙摆、挂饰及指趾，交用户确认。既有认可图可直接作为该关口成果，不要求重画。

## 三视图

使用一致的近正交表现，正、侧、背排列并标注方向；同尺度、同站姿、同脚底线。对齐头顶、眼线、肩、手腕、自然发梢、裙摆和脚踝；不要让每幅图单独居中缩放后误以为比例一致。

不是将三张不同人物拼在一起，也不是将正面翻转作为背面。逐项核对：

- 非对称眼色、精灵耳与猫耳等配饰身份；侧面可见的是哪一只眼。
- 项链、花、蝴蝶结与尾饰的正/侧/背投影和遮挡；侧面不应看到完全展开的正面蝴蝶结，除非其真实结构如此。
- 发梢高度与头发位于身体前后的关系；背面应有与前侧图一致的遮挡。
- 手势不变时，前后观察的近远手指及拇指虎口位置应相互解释。
- 同一衣物的层数、接缝、裙长、环带与花的方向性。

光照采用统一约定，记录在规格中。为颜色判读，可约定每幅视图各自以镜头正面柔光照明；这是二维制图约定，不是假定同一个世界光源同时位于三个方向。

## 修订与回退

维护“已认可基线”和“最新候选”两个字段。新增候选不自动更新已认可基线。用户让回到旧版本时，以其明确指定为准，不将旧分支被否定的其他改动重新合入。

每轮填写一张变更单：

```text
底图及 SHA256：唯一实际编辑输入。
特征参考：参考图 + 对应视图/部位；其余内容无效。
目标：可观察的一项或紧密相关的一组改动。
允许区域：视图 + 部位，必要时保存掩模。
保持项：比例、轮廓、色彩、纹理、配饰等本轮不能改变的变量。
方法：生成式局部编辑 / 裁剪回贴 / 掩模颜色变换等。
验收：局部目标 + 全图漂移检查 + 选区外变化（适用时）。
失败回退点：上一认可图；候选不叠加作为新底图。
```

需要裁剪时留足上下文，禁止随意缩放、透视变换后回贴。掩模外原像素保留，过渡仅限约定的边界带；检查发丝、手指和白背景接缝。若仅使用整图生成式编辑，诚实标记无法保证其他区域逐像素一致。

结构问题反复失败时，先把局部放大并描述近远关系，再生成候选。手部必要时单独做大图验证后合成；不能只用“真实、正确”替代可检验的遮挡定义。

## 颜色与降噪

将造型、色相、饱和度、明度、局部对比和底噪分开判断。配色匹配但保留旧明度，会继续显灰；白材质局部存在很深灰影，即使平均值高，视觉上仍可能发黑。

1. 在参考图同一材质、相似受光的小范围取样，保存坐标、像素数量、RGB 中位数/均值及 HEX。不要用一个含阴影的点概括整块皮肤。
2. 分材质设柔和掩模；区分白发/白裙、紫色配饰、皮肤与耳内色、镂空内色、背景。不用全图统一偏移破坏眼睛和宝石。
3. 仅改色时不移动、重采样或重画轮廓。用连续曲线和软边权重减少阈值边缘碎斑；输出前看掩模及边界。
4. 需要纯白背景时只处理经确认的背景区域；可用边界连通近白区域辅助识别，不能将角色内部浅白材质一并刷白。透明背景任务则保留透明，不默认改成白底。
5. 对噪声采用保边降噪并保护线条、花纹和发束；生成式“去噪”可能重新引入纹理，需用相同 ROI 的处理前后统计确认是否改善。
6. 正常显示、低对比度显示、局部放大一起复核。平坦背景标准差和高频残差只是局部代理，真实衣褶也产生残差，不能据此宣称全图无噪声。

中文色名不是唯一标准。推荐写法：“低饱和浅粉象牙白，以指定小腿受光区为参考，中间色约 #FEEEEA，阴影同色系连续过渡，脸颊仅轻微粉红”。这是本次案例的示例，不是所有角色默认肤色；显示器和光照会影响观感。

## 验收、冻结与交接

| 检查 | 通过条件 |
|---|---|
| 身份与比例 | 与已认可设计一致，不因修手脚改变四肢围度 |
| 多视图 | 高度、姿态、配饰投影、遮挡和左右关系能互相解释 |
| 手足 | 局部能看清近远关系、形状与脚踝过渡，无多指和尖刺 |
| 材质 | 同材质连续，没有意外斑块、偏红、脏灰和新增底噪 |
| 修改范围 | 若承诺像素保持，则掩模外变化和 alpha 检查满足约定 |
| 版本 | parent 明确，候选/认可/否定分开，未解决项未被藏起 |
| 用户关口 | 有用户认可依据；“暂定最终”保留暂定状态 |

冻结包：原尺寸最终图、SHA256、规格、色板、方向说明、必要部件细节、最新修订记录和未解决项。需要分图输入三维服务时，另存正/侧/背裁剪，保持尺度与全部轮廓、不拉伸，标明角色自身左右；不要把整张拼图默认当作单视图送入服务。

外部三维服务单独确认输入格式、模型版本、任务记录与费用授权。先验收一个输出的多角度相似度，再决定重拓扑、分件、绑定与动画。静态好看不等于可以直接换装、说话或执行全部动作。
